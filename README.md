# OAuth consent screen prototype

Clickable product mockup for the OAuth consent-screen redesign. This is not a
Zendesk production page. It uses fictional account and application data.

## View it

Once GitHub Pages has deployed: https://kellokello.github.io/oauth-consent-screen-mockup/

Use the selector in the prototype bar to switch between:

1. Standard consent with a logo
2. Standard consent without a logo
3. Consent from an external AI agent
4. Broken or expired link

## Run locally

```bash
npm install
npm run dev
```
